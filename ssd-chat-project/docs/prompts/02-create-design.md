# 工程2：詳細設計

共通ルール、承認済みrequirements.md、必要な既存コード・環境制約を入力してください。

## 指示
1. 仕様IDごとに実現方法を設計し、design.mdの構成で出力する。
2. 処理フロー、クラス・メソッド、入出力型、データアクセス、例外、ログを具体化する。
3. 設計判断と仕様から直接決まる事項を区別する。
4. 仕様にない業務ルールが必要なら質問し、勝手に追加しない。
5. 全仕様IDを対応表に載せ、対応漏れを指摘する。
6. 既存コードに変更を加える場合は変更対象と非対象、互換性上の懸念を示す。

## 出力
- design.md全文
- 仕様ID→設計箇所の対応表
- 設計上の選択肢と承認事項

重大な未決定事項が残る場合はコード生成への移行不可と明記してください。
