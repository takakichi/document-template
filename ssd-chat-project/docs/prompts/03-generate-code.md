# 工程3：コード生成

共通ルール、承認済みrequirements.md、承認済みdesign.md、開発環境・対象ファイル情報を入力してください。

## 指示
1. 承認済み設計の範囲内でC#コードを生成する。
2. 生成対象のファイル一覧と変更理由を最初に示す。
3. 各ファイルをパス付きで完全なコードブロックとして出力する。
4. 仕様IDと実装箇所の対応表を示す（必要な箇所にコメントを追加してよい）。
5. 既存公開インターフェースやDBを無断変更しない。
6. コンパイル未確認なら「未実施」と明記する。
7. ビルドエラーを受け取った場合は、原因、最小修正案、影響範囲を提示する。

## 出力
- ファイル一覧
- 生成コード
- REQ→ファイル・メソッド対応表
- ビルド手順と未確認事項

実行・ビルドしたと偽らないでください。
