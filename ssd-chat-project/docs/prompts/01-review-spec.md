# 工程1：仕様レビュー・確定支援

共通ルール（common-rules.md）と仕様書草案（requirements.md）を入力として使用してください。

## 指示
1. 各REQを読み、曖昧さ、矛盾、欠落、実装不能な条件、試験不能な表現を点検する。
2. 入出力、境界値、異常時、権限、データ条件、対象外を確認する。
3. 問題を「重大／通常／軽微」に分類し、根拠となる見出し・仕様IDを示す。
4. 確認質問を優先度順に提示し、回答候補は提案として区別する。
5. 回答がない事項を推測して確定しない。
6. 承認に必要な未解決事項があれば「仕様確定不可」と判定する。

## 出力
- 仕様レビュー結果表（ID、問題、影響、質問、推奨案）
- 仕様書の修正案（差し替え対象箇所のみ）
- 確定可否と承認待ち事項

人間が回答した後は、その回答だけを反映した改訂版の全文を作成してください。承認済みの表示は人間の明示承認後に限ります。
