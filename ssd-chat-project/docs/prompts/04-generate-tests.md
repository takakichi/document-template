# 工程4：試験項目・試験コード生成

共通ルール、承認済みrequirements.md、承認済みdesign.md、テスト環境・使用可能なフレームワークを入力してください。
コードはテスト対象APIを確認するための補助資料としてのみ参照し、期待結果は仕様から決定してください。

## 指示
1. 仕様IDごとに正常・異常・境界・権限・0件・データ条件を必要に応じて洗い出す。
2. 前提条件、入力、期待結果を具体的に記載する。
3. 試験ID（TC-001等）を付与し、仕様IDと対応させる。
4. 実装できる自動試験コードを生成する。外部依存のため自動化困難な試験は手動試験として分ける。
5. 実装コードと仕様が異なる場合、期待結果を実装に合わせず不一致として報告する。
6. 試験未実施を成功と記載しない。

## 出力
- test-cases.md全文
- テストコード（ファイルパス付き）
- 仕様ID→試験ID対応表
- 未網羅事項と試験実行手順
