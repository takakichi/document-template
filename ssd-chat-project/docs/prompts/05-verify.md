# 工程5：検証・整合性レビュー

共通ルール、承認済みrequirements.md、design.md、生成コード、test-cases.md、試験コード、実際のビルド・試験ログを入力してください。

## 指示
1. 各REQについて設計・実装・試験の対応を検証する。
2. 仕様と実装、仕様と期待結果、設計と実装の不一致を列挙する。
3. 実際のビルド・試験ログから成功、失敗、未実施を区別する。
4. 不適合を重大度順に整理し、根拠、再現条件、修正対象工程を示す。
5. 修正後に再実行すべき試験を示す。
6. 全件成功を推測しない。証跡不足は「未確認」とする。

## 出力
- review.md全文
- REQ→設計→実装→TC対応表
- 不適合一覧と修正提案
- 最終判定（合格候補／要修正／判定保留）と人間の承認待ち事項
